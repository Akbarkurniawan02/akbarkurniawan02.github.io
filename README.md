# تک‌روز ⚡

سایت و ارسال خودکار پست‌های کانال تلگرام [@techrooz_fa](https://t.me/techrooz_fa).

- سایت: https://techrooz.github.io
- `queue.json`: صف پست‌ها (فقط محتوای عمومی کانال)
- `scripts/post_queue.py`: ارسال سر ثانیه به تلگرام (توکن فقط در GitHub Secrets)
- `scripts/build_site.py`: ساخت سایت از پست‌های منتشرشده
